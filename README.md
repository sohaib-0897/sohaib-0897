## Selected Projects

### [VigilAI](https://github.com/sohaib-0897/VigilAi)
**Real-time computer vision and video analytics**

End-to-end video analytics system for detecting, tracking, and turning camera activity into reviewable events.

- YOLO inference with PyTorch and ONNX Runtime
- ByteTrack multi-object tracking with persistent identities
- Stateful zone, line-crossing, dwell, occupancy, and PPE rules
- Bounded frame buffering and separate CV worker architecture
- PostgreSQL-backed events with annotated evidence
- Reproducible CPU inference benchmarks and held-out model evaluation

`Python` `FastAPI` `ONNX Runtime` `OpenCV` `ByteTrack` `PostgreSQL` `Redis` `Next.js`
